# Coop

**БЭДТРИП** (рабочее название) — acid schizo-punk 3D-шутер 2×2 с войсом и карточным хаосом.

- 📄 [Дизайн-документ](docs/game-design.md) — концепция, герои, карты, войс-механики, план прототипа.

## Быстро

- **Формат:** 2×2, best of 5, короткие раунды.
- **Герои:** ШИЛО (DPS), СПОРА (саппорт), ГОЛОСА (трикстер), ЖИЖА (танк).
- **Фишки:** голос = ускорение (болтаешь в микрофон — бежишь быстрее, тишина ничего не даёт), абсурдные карточки-апгрейды и карточки-руины для соперников.
